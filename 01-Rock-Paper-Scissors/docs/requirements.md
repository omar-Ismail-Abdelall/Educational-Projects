# Requirements

## Project Description

The project is a simple Rock Paper Scissors game where the user plays against the computer.

## Functional Requirements

1. The program should allow the user to choose Rock, Paper, or Scissors.
2. The computer should make a random choice.
3. The program should compare the user's choice with the computer's choice.
4. The program should determine the winner according to the rules of Rock Paper Scissors.
5. The program should display the user's choice, the computer's choice, and the final result.

## Learning Objectives

- Practice working with lists and data.
- Practice using variables.
- Practice using conditional statements (`if`, `elif`, `else`).
- Practice working with user input.
- Practice using random selection.
